# AI生产排程优化系统测试说明

后端测试覆盖：

1. 产品元数据、健康检查、未登录拦截、目录和看板；
2. 创建、修改、删除、重复编号、非法模块与服务端状态机；
3. 角色权限、管理员设置、操作审计、评论与时间线；
4. 组合检索、分页、SLA统计和CSV导出；
5. 企业控制项幂等、职责分离、审批、附件凭证、办结和外部回执；
6. AI生产排程优化系统专属领域决策、指标、评分和认证要求；
7. prod profile 默认凭据和跨域安全门禁。

执行命令：

```bash
cd backend && mvn test
cd ../frontend && npm ci && npm run build
docker compose config
```

测试数据库使用 H2；生产数据库为 MySQL 8。自动化测试通过不替代生产容量测试、渗透测试、灾备演练和业务 UAT。
